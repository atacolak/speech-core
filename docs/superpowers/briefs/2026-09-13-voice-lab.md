# Voice lab workbench (profile, not a single reference)

**Status:** settled
**Source:** operator request 2026-09-13 (this chat)
**Repo:** speech-core

## Intent

The "edit reference" modal is too small. A voice is a **profile**,
not one wav. AuK is the offline refinery; Breeze is the realtime
mouth. They do not share the 4070. The lab is a workbench for
building reusable Breeze references.

```text
sources → auk → experiments → approve → references → breeze
```

Do not polish the modal. Replace it.

## Ontology

```text
voice
├── sources       immutable origin audio (many)
├── experiments   auk (and specialist) candidates
└── references    approved for breeze (many; one optional default)
```

Do not call every clip a reference.

## GPU

AuK XOR Breeze. Audition is staged: save artifact → unload auk →
load breeze → synthesize → keep the take on the experiment.
Swap time is fine. The artifact outlives either runtime.

## Surface

Workbench, not a crop modal. Assets / workbench / inspector /
compare. Intent modes: CLEAN / ISOLATE / PERFORM / EDIT /
SYNTHESIZE. Natural-language instruction first-class. Precision
(bf16/int8) is diagnostics, not a chip next to generate.

Waveform is an instrument (play/keep/exclude/crop/zoom), not a
DAW. Generate 2–3 candidates. A/B is the product.

## Specialists

Stream.fm dead. Resemble/VibeVoice parked. Survive only if they
earn it vs AuK (diarization ≠ separation).

## Success

Multi-source, multi-reference, distinct roles, immutable sources,
lineage, intent modes, useful waveform, cheap multi-candidate
compare, playground picks a reference, breeze audition via swap,
precision hidden, specialists reconsidered.
