# AuK as the lab reference refinery (upstream of Breeze TTS2)

**Status:** settled
**Source:** operator request 2026-09-12 (this chat)
**Repo:** speech-core

## Intent

Reconsider the speech-core voice lab around **AuK** as the
primary **offline** speech/reference refinery. Breeze TTS2 stays
the realtime cloned-voice mouth. AuK does not replace Breeze.

```text
existing / recorded audio
        ↓
      AuK lab
        ↓
clean / isolated / transformed / synthesized reference
        ↓
approved reference bank
        ↓
   Breeze TTS 2
        ↓
realtime speech
```

The lab's job is to turn arbitrary source material into excellent
reusable Breeze references. Do not bolt AuK beside Resemble /
VibeVoice / Stream.fm. Default path is AuK; specialists survive
only where they earn the extra stack.

## Ownership split

- **AuK (offline):** prepare, isolate, perform, transform,
  synthesize candidate references. Instruction-guided.
- **Breeze (realtime):** cloned-voice synthesis + per-utterance
  steer. Consumes an **approved reference artifact**, never a
  live AuK session.
- **Diarization (parked):** speaker-at-time labels
  (`S1 00:01–00:08`). AuK can emit isolated speech; it does not
  replace timestamped analysis. VibeVoice stays parked until
  AuK separation is measured and found wanting.

## Deployment (12 GB RTX 4070)

Preferred pin, quality-first, latency secondary:

```text
auk_base_bf16.safetensors     ~3.062 GB
qwen_omni_w4a8.safetensors    ~3.179 GB
auk_vae.safetensors           ~0.637 GB  (unquantized / fp32)
stored total                  ~6.88 GB
```

- Base, not Flash. 32-step guided generation is the quality path.
- Quantize the Qwen conditioner first. Keep AuK diffusion in
  bf16. Keep VAE unquantized.
- Encoder / model / VAE independently loadable and offloadable.
  Do not pin every component on GPU.
- **No ComfyUI dependency.** Port quantized loading from
  `Saganaki22/ComfyUI-AuK` / `drbaph/AuK-comfyui` into our
  stack. Official `Tencent-Hunyuan/AuK` `AukInfer` is the
  behavioural reference, not the 4070 deploy (it wants a full
  Qwen2.5-Omni-3B thinker).
- int8 AuK (`auk_base_int8` + same w4a8 encoder + fp32 VAE) is
  an **explicit** memory fallback. Never silent. Comparison
  against the bf16 ceiling must stay possible.
- Flash later only if a real UX need for faster previews exists.
- Weights live under `~/.local/share/speech-out/`, not the repo.

## Validate before trusting

Build a small set from real reference material. At least:

raw → enhance / denoise / dereverb-repair;
multi-speaker → speaker separation / target-speaker extraction;
clean voice → emotion / timbre / speed-pitch-energy / nonverbal.

For important reference-production tasks, A/B:

`AuK base bf16 + qwen w4a8` vs `AuK base int8 + qwen w4a8`.

Listen for identity drift, accent wash, metallic diffusion,
over-restoration, consonant damage, invented breath/noise,
emotion that changes identity.

Do not present every advertised task as equally deterministic.
Community ranking (Saganaki22, treat as prior not proof):

- more reliable: tts/clone, enhance, denoise, speaker
  separation, quality repair, volume
- less reliable: emotion, target-speaker, timbre, pitch/speed,
  accent, nonverbal, content edits

The lab must show that ranking.

Separately measure whether AuK-authored emotion/prosody
**survives Breeze conditioning** (same text/steer against
neutral/warm/angry/soft/high-energy references). That result
shapes the reference bank. Do not assume AuK performance
basins stick.

## Lab surface

Do not add an "AuK" tab. Redesign around:

SOURCE (import/record, waveform, crop, transcript) →
PROCESS (prepare / isolate / perform / transform / synthesize,
task presets + short freeform instruction) →
CANDIDATES (instant A/B, provenance) →
REFERENCE BANK (approve, name, tags, transcript) →
BREEZE (approved reference + realtime steer).

Smallest UI that makes the loop obvious. Advanced knobs
(nfe/cfg/sway/attention) live behind debug. Sane task presets
own those values. Instruction builder in the spirit of the
community workflow, not ComfyUI's graph.

A/B must be unusually cheap: "cleaner" can still be a worse
clone reference if identity moved.

Downloads/exports are explicit. Hearing a candidate is not an
export.

## Artifact model

Processed audio is an artifact, never widget state. Source is
immutable. Candidates keep enough provenance to reproduce:

source, crop/range, AuK task, instruction, model variant,
precision (auk + encoder), seed, generation settings, output,
created_at, approval status.

Branching exists even if the UI is not a graph:

```text
raw → enhanced → warm
    → speaker-isolated → repaired → deadpan
```

An approved artifact promotes to a Breeze reference: audio +
speaker identity + name + transcript + AuK provenance + tags.
Distinguish **reference prior** (stable basin) from **runtime
steer** (transient Breeze direction).

## Non-goals

ComfyUI in speech-core. AuK-Flash as default. Silent int8
fallback. Dual-occupancy AuK + Breeze on the 4070. Voicecat
adapter retune. Pin swap of the live mouth. Closing
`sc-lab-ref-prep-un2z` without operator close. Implementing
parked vibevoice/mossformer/TSE.

## Success

1. AuK Base runs locally on the 4070 as bf16 AuK + w4a8 Qwen +
   fp32 VAE, with sensible offload.
2. Real enhance/separate/edit workloads fit well enough to use.
3. int8 AuK is an explicit fallback, compared against bf16.
4. Source immutable; variants keep provenance; branching real.
5. Useful AuK surface, not a knob pile.
6. Raw vs processed A/B is trivial.
7. Promote into the reference bank.
8. Approved refs audition through Breeze TTS2.
9. Measured: does AuK emotion/prosody survive Breeze?
10. Stream.fm/VibeVoice/Resemble reconsidered in writing;
    redundant default path removed or parked.
11. Informed by community AuK workflows; still our lab.
