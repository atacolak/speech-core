# Voice lab workbench Technical Spec

**Design Brief:** `docs/superpowers/briefs/2026-09-13-voice-lab.md`
**Status:** sound
**Repo:** speech-core

## Intent (do not rewrite)

A voice is a profile: many sources, many experiments, many
approved references, one optional default. Replace the
edit-reference modal. AuK XOR Breeze on the 4070. Artifacts
outlive either runtime.

## Mapping onto the current system

Today `voices` is 1:1 with `source_artifact_id` +
`keep_intervals` + `active_reference_variant_id`.
`reference_variants.kind` is `original | resemble | auk | other`
with auk lineage columns (`parent_variant_id`, `approved`, …).
The editor is a modal crop + PROCESS chips from t4. Playground
synthesizes the active variant only. GPU lease already unloads
Breeze with `restore_leftover=False`. t3 is landing isolated AuK
runtime. Do not revert leftover hop / desk contract.

Migrate. Do not keep a parallel "edit reference" object.

## Data

Replace the single-source voice with:

```text
voices                  profile (name, tags, default_reference_id)
voice_sources           many immutable origin artifacts per voice
                        (label, artifact_id, transcript, words, keep)
voice_artifacts         experiments + references
                        role: experiment | reference
                        parent_id, source_id, crop, auk provenance,
                        approved_at, name/tags, default flag
breeze_auditions        attached to a voice_artifact
                        (text, steer, generation, output, when, pin)
```

`reference_variants` may be migrated into `voice_artifacts`
(role=reference if approved else experiment; kind=original becomes
a source). Keep-interval math stays. Source bytes never overwritten.

## HTTP (lab-only)

- `GET/POST /api/voices/{id}/sources`  add/list
- `POST /api/voices/{id}/auk` already planned; body names
  `source_id` or `parent_artifact_id`, `count` 1–3
- `POST /api/voices/{id}/artifacts/{aid}/approve` → role=reference
- `POST /api/voices/{id}/default-reference` `{artifact_id}`
- `POST /api/voices/{id}/audition` staged: unload auk, load
  breeze, synth, attach take, leave breeze loaded or not as
  requested
- Playground: `GET /api/voices/{id}/references` and synthesize
  takes `reference_id`

Fail closed: 409 live_call, 409 runtime_busy, 501 auk missing,
never silent int8.

## UI

Kill the modal. Workbench occupies the lab center (or replaces
the three-pane crop overlay):

- ASSETS: sources / references (★ default) / experiments + add
- WORKBENCH: waveform instrument + intent modes (CLEAN ISOLATE
  PERFORM EDIT SYNTHESIZE) + instruction + generate N
- INSPECTOR: selected artifact lineage/tags (quiet)
- COMPARE: source vs 2–3 candidates, approve on the card

Precision / nfe / cfg behind diagnostics. Occupancy chrome:
**AuK** or **Breeze**, never leftover-parked / qwentts.

Intent modes map to cookbook presets (t4 `auk-tasks.ts` regrouped).
NL instruction remains the escape hatch.

## Breeze audition

Explicit swap. Same text/steer/generation across a set of
references. Result pinned on the artifact. Survives swapping
back to AuK.

## Specialists

Stream.fm dead. Resemble/VibeVoice stay in code, unmounted.
Diarization may return later as timeline, not as default isolate.

## Non-goals

ComfyUI. DAW. Dual occupancy. Automatic runtime reference
picking. Leftover env rename. Closing t3 from this epic.
Pin swap.

## Approach

**Chosen:** migrate `voices` off 1:1 source; artifacts table
with role; workbench replaces modal; audition is a staged
runtime recipe on existing lease.

**Rejected:** keep modal and add a "references" tab. Graph UI.
Silent int8. Audition that assumes both models resident.
