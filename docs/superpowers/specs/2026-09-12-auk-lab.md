# AuK lab Technical Spec

**Design Brief:** `$HOME/workspace/speech-core/docs/superpowers/briefs/2026-09-12-auk-lab.md`
**Status:** sound
**Repo:** speech-core

## Intent (from the Brief — do not rewrite)

AuK is the offline reference refinery. Breeze TTS2 is the realtime
cloned-voice mouth. Do not replace Breeze. Do not bolt AuK beside
Resemble/VibeVoice. Default path is AuK; specialists survive only
where they earn it. Preferred 4070 pin is bf16 AuK Base + w4a8 Qwen
encoder + fp32 VAE. No ComfyUI dependency. int8 AuK is explicit,
never silent. VibeVoice is parked. Dead leftover env keys stay until
the leftover daemon rebuild.

## Mapping onto the current system

Observed in the **current worktree** (do not revert leftover hop /
Breeze runtime / desk contract):

- Three-pane lab: voices / synthesis / inspector + modal
  `ReferenceEditor` (waveform, keep/exclude, denoise radios,
  analyze-speakers chips, occupancy strip).
- Artifact store: sqlite + content-addressed audio. Voices have
  `source_artifact_id`, `keep_intervals`, transcripts,
  `active_reference_variant_id`. `reference_variants.kind` is
  `original | resemble | other`.
- GPU: `E2RuntimeManager` + `ProcessorLease`. Processors unload
  Breeze with `restore_leftover=False`. Live-call lease blocks
  competing lab generate. 4070 cannot co-reside Breeze (~9 GiB)
  with AuK (~7 GB stored, more at peak) or VibeVoice (8150 MiB)
  or Resemble (3348 MiB).
- Resemble denoise-only landed (`kind=resemble`). Stream.fm routes
  already 404.
- VibeVoice NF4 analysis + use-speaker keep landed, but the shared
  Breeze venv is pinned `transformers==4.57.3` so
  `VibeVoiceAsrForConditionalGeneration` does not import. Peak
  occupancy is measured. Parser accepts capitalized NF4 keys.
- Leftover mouth `:8788` hops `POST /internal/leftover/v1/audio/speech`
  into the loaded Breeze worker. Overlay leftover hop. Not a pin
  swap. Live env still uses `SPEECH_OUT_COSYVOICE_*` /
  `SPEECH_OUT_QWENTTS_*`.

Reuse: artifact store, keep math, GPU lease, Breeze audition path,
immutable source. Do not invent a second voice store.

## Architecture

```text
source artifact (immutable)
  -> crop / keep_intervals
  -> AuK task (instruction + seed + precision)
       -> candidate artifact (kind=auk, parent_id, provenance)
  -> A/B vs source or sibling candidate
  -> approve -> Breeze reference (active variant)
  -> Breeze synthesize / leftover hop
```

One GPU occupant at a time: `breeze | auk | resemble | (parked vibevoice)`.
AuK runtime is a **separate venv + subprocess**, same idea as the
Breeze worker. Encoder, diffusion, VAE independently loadable /
offloadable. After an AuK run, leftover stays parked, Breeze stays
unloaded unless the operator reloads.

int8 AuK is a second named pin, selected in the UI, never an
automatic downgrade when bf16 OOMs. OOM fail-closes with measured
free/required.

## Components

### Runtime

New `tts/lab/backend/runtime/auk.py` (name flexible) owned by lab
state:

- pin dir `~/.local/share/speech-out/auk-base/` (weights, not repo)
- preferred: `auk_base_bf16` + `qwen_omni_w4a8` + `auk_vae`
- fallback pin: `auk_base_int8` + same encoder + same VAE
- load/offload encoder, model, vae independently
- generate(task, instruction, source_wav, seed, settings) → wav
- fail closed if weights missing, CUDA OOM, or live_call_active

Quantized loading: port the **weight format** from
`Saganaki22/ComfyUI-AuK` (`auk_base_bf16.safetensors` metadata,
`qwen_omni_w4a8`, unquantized VAE). Do **not** import `comfy.*`.
If Comfy Kitchen quant ops are the only way to run w4a8, isolate
that as a tiny local ops layer or document the blocker — do not
pull ComfyUI.

Official `AukInfer` is the behavioural oracle (ChatML instruction +
optional audio, 24 kHz mono out, Base nfe=32 cfg=2 sway=-1). It
loads a full Qwen thinker and is not the 4070 deploy.

Flash is out of scope.

### Tasks

Task id owns the cookbook instruction template and default
sampling. Operator sees a short verb + optional freeform
refinement, not nfe/cfg.

Default (show, higher confidence):

- enhance, denoise, repair
- separate speaker (by talking order)
- clone / generate candidate speech from a description
- volume

Behind "more" / lower confidence chrome:

- target speaker by spoken content
- emotion, timbre, whisper, accent, nonverbal
- speed, pitch
- content edit

Do not hide the less-reliable tasks; mark them.

### Artifacts

Extend `reference_variants` (or a sibling `candidates` table if a
variant row cannot hold parent/lineage without lying):

| field | meaning |
|---|---|
| parent_variant_id | branch point (null = source/original) |
| kind | `original \| auk \| resemble \| other` |
| auk_task | enhance / denoise / separate / … |
| instruction | exact text sent to the model |
| model_variant | `auk-base` |
| auk_precision | `bf16` \| `int8` |
| encoder_precision | `w4a8` |
| seed | |
| settings_json | nfe/cfg/sway if non-default |
| audio_artifact_id | |
| approved | bool; approved ones may become Breeze refs |
| stale | true if source/keep no longer match |

Source never overwritten. Hearing a candidate is not an export.

### HTTP (lab-only)

- `GET /api/auk/runtime` — occupancy, loaded components, pin,
  precision
- `POST /api/auk/runtime/load` `{precision?: "bf16"|"int8"}` —
  parks leftover, unloads Breeze, loads AuK. 409 live call.
- `POST /api/auk/runtime/unload` — drops AuK, leftover stays
  parked, Breeze stays unloaded
- `POST /api/voices/{id}/auk` — run a task on current keep (or
  named parent candidate); returns voice + new candidate
- `POST /api/voices/{id}/reference/activate` already exists;
  approved AuK candidate becomes the clone audio
- `POST /api/voices/{id}/auk/approve` — mark candidate as
  reference-bank member

Resemble denoise route may stay for the specialist bakeoff. Do not
put it on the default editor surface.

VibeVoice `/speakers/analyze` and `/speakers/use` stay in code,
unmounted from the default editor.

### UI

Redesign the reference editor around SOURCE → PROCESS →
CANDIDATES → (approve) → Breeze. Not a new top-level pane if the
modal editor can carry it; not an "AuK" tab.

Must-haves:

- drop/import/record, waveform, crop
- task chips with confidence, instruction box
- generate candidate
- instant A/B (source vs candidate, candidate vs candidate)
- provenance line (task, instruction, precision, seed)
- approve as Breeze reference
- audition in Breeze (existing synthesize / leftover hop)

Advanced knobs behind debug. Occupancy chrome says **Breeze** or
**AuK**, never leftover-parked / not-a-pin-swap / qwentts /
cosyvoice.

### Specialists

- Stream.fm: remains deleted.
- Resemble: keep service + tests; remove from default editor;
  bakeoff vs AuK enhance is a later measured child, not the
  first frontier.
- VibeVoice: keep parser/tests; unmount UI; do not load the
  model; do not install transformers 5.3 into the Breeze venv.
- mossformer / TSE / streaming vibevoice: still parked.

## GPU / lease

Same `ProcessorLease` idea, occupant `auk`. Unload Breeze with
`restore_leftover=False`. Never auto-reload Breeze after AuK.
Live call → 409, no unload. OOM → error, AuK unloaded, leftover
still parked.

## Validation (measured, not inferred)

1. Preferred pin loads on this 4070. Record peak `nvidia-smi`
   memory.used for enhance + separate + one edit, with
   independent offload.
2. Same inputs through int8 pin. Operator-audible A/B vs bf16.
   No silent switch.
3. Source bytes unchanged after generate.
4. Candidate provenance round-trips (re-run same seed/settings
   produces a comparable artifact; exact bitwise match is not
   required).
5. Approve → Breeze synthesize uses that wav, not the raw source.
6. Emotion/prosody survival matrix: five AuK-authored refs
   (neutral/warm/angry/soft/high-energy), identical Breeze
   text+steer. Written listen notes. Shapes the bank UI.
7. Default editor has no Analyze speakers / Resemble denoise /
   stream.fm / qwentts / cosyvoice chrome.

## Non-goals

ComfyUI. Flash default. Dual occupancy. Voicecat retune. Pin
swap. Implementing parked vibevoice. Silent int8. Closing the
resemble epic without operator close.

## Approach chosen (and rejected)

**Chosen:** separate AuK venv + subprocess; port quantized
checkpoints without ComfyUI; extend artifacts with lineage;
redesign the editor around candidates; park vibevoice; keep
Resemble code for a later bakeoff.

**Rejected:** official `AukInfer` + full Qwen 3B on the 4070
(does not fit beside itself, let alone with headroom). ComfyUI
as a speech-core dependency. Stacking AuK on top of Resemble +
VibeVoice as three default processors. New graph UI.
